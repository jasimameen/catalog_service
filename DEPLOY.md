# Deploy

1. Finish [`SETUP.md`](SETUP.md).
2. Import the repo on [Vercel](https://vercel.com/new), or `npm run build && npm run start` on any Node host.
3. Paste the same vars from `.env.example`. Production: `NEXT_PUBLIC_ROOT_DOMAIN=catalog.hevyf.com`.
4. Point DNS and custom domains with [`CLOUDFLARE.md`](CLOUDFLARE.md).
